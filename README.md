# Minhas Anotações

Aplicativo de anotações simples e acessível, pensado para guardar informações importantes de forma rápida e fácil.

## Stack

- Next.js + React + TypeScript
- shadcn/ui-style components
- Tailwind CSS
- Geist
- Lucide React
- Persistência local com `localStorage`

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Funcionalidades

- Criar e editar anotações
- Buscar anotações
- Categorizar informações
- Fixar informações importantes
- Excluir anotações com confirmação
- Interface responsiva para celular, tablet e desktop
- Dados persistidos no dispositivo
